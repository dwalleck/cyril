## Architecture

Both public and renderer-facing APIs share the same private decoder, parameterized by Display versus Error policy. Incoming `error`/`message` selections fit the existing `ToolTextSource::RawField(&'static str)` representation; no new selector variant is needed.

Presentation retains `Source::Tool(selector)` and byte ranges, not a `Cow` borrowing across frames. Painting resolves them through `Sources::external` → `resolve_text_source`. Derived JSON owns retained generated backing instead.

Relevant connections:

- `UI/src/widgets/chat/presentation.rs:18-35,54-109,669-725` — source representation, resolution, borrowed/derived handling.
- `UI/src/widgets/chat/retained.rs:117-160` — changed history positions are re-prepared.
- `UI/src/widgets/chat/retained.rs:307-346` — preparation receives current message sources; paint resolves retained source slots.
