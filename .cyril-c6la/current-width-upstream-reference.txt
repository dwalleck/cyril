## CellWidth conversion contract

- Public trait, not a numeric newtype:
  ```rust
  pub trait CellWidth {
      fn cell_width(&self) -> u16;
  }
  ```
  Implemented for `str`; `Cell` also implements it, honoring `CellDiffOption::ForcedWidth` before measuring its symbol.
- Public export: [core `buffer.rs:12`](https://github.com/ratatui/ratatui/blob/e665c36cb14752a61cd777fbd06dbef8474f2add/ratatui-core/src/buffer.rs#L12). The facade [reexports `buffer`](https://github.com/ratatui/ratatui/blob/e665c36cb14752a61cd777fbd06dbef8474f2add/ratatui/src/lib.rs#L480), yielding the approved import:
  ```rust
  use ratatui::buffer::CellWidth;
  ```
- On borrowed graphemes, replace raw measurement with `grapheme.symbol.cell_width()`. For long-text totals, widen **each result** with `usize::from(...)` before summing.
- Exact implementation: one-byte strings return 1, with a debug assertion rejecting ASCII controls. Otherwise it computes `UnicodeWidthStr::width(...) as u16`, then saturating-adds the number of FF9E/FF9F occurrences. **Do not describe it as globally overflow-safe whole-string measurement:** its raw width and count each contain `as u16`.
- FF9E/FF9F gain one physical cell per occurrence, including marks attached to non-katakana bases. U3099/U309A receive **no adjustment**.
- `cell_width()` itself does not sanitize control content; retain `styled_graphemes` filtering before measurement.

Sources: [cell_width.rs:19–74](https://github.com/ratatui/ratatui/blob/e665c36cb14752a61cd777fbd06dbef8474f2add/ratatui-core/src/buffer/cell_width.rs#L19-L74), [cell.rs:309–317](https://github.com/ratatui/ratatui/blob/e665c36cb14752a61cd777fbd06dbef8474f2add/ratatui-core/src/buffer/cell.rs#L309-L317).

## Carry defect and classifier

**[INFERENCE: direct state trace]** At width 2, `"a界a"` still produces reference descriptors equivalent to:

1. `"a"` becomes `pending_line`, width 1.
2. `"界"` remains a carried `pending_word`, width 2.
3. The final `"a"` triggers emission of `pending_line`.
4. Upstream resets `line_width` but does **not** emit/recheck the now-full carried prefix before appending `"a"`.
5. Final reference rows are `"a"` and `"界a"`; the latter has width 3 and its `"a"` starts at column 2, outside the width-2 row.

The unchanged responsible branch is [reflow.rs:127–168](https://github.com/ratatui/ratatui/blob/e665c36cb14752a61cd777fbd06dbef8474f2add/ratatui-widgets/src/reflow.rs#L127-L168).

C6’s existing correction must remain: emit a full carried prefix **before another positive-width symbol starts outside the row**, not before every symbol whose end would overhang.

The existing `legacy_reference_is_unsafe` must classify the **unrepaired 0.3.2 physical-width reference**, preserving original span boundaries. Its essential predicate remains:

```text
advance > 0 && start_x >= target_width
```

It must not classify legal final overhang or zero-width symbols as unsafe. Both the unrepaired classifier composition and its advance measurements need the new width contract; retaining raw-width measurement would miss newly exposed halfwidth-mark cases.
