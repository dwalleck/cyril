Usage: kiro-cli settings [OPTIONS] [KEY] [VALUE]
       kiro-cli settings <COMMAND>

Commands:
  open  Open the settings file
  list  List settings
  help  Print this message or the help of the given subcommand(s)

Arguments:
  [KEY]
          key

  [VALUE]
          value

Options:
  -d, --delete
          Delete a key (No value needed)

      --global
          Set or delete in global settings (default)

      --workspace
          Set or delete in workspace settings

  -f, --format <FORMAT>
          Format of the output

          Possible values:
          - plain:       Outputs the results as markdown
          - json:        Outputs the results as JSON
          - json-pretty: Outputs the results as pretty print JSON
          
          [default: plain]

  -v, --verbose...
          Increase logging verbosity

  -h, --help
          Print help (see a summary with '-h')
