Account commands, the same as the top-level login, logout, whoami and profile

Usage: kiro-cli user [OPTIONS] <COMMAND>

Commands:
  login    Log in to Kiro
  logout   Log out of Kiro
  whoami   Print info about the current login session
  profile  Show the profile associated with this idc user
  help     Print this message or the help of the given subcommand(s)

Options:
  -v, --verbose...  Increase logging verbosity
  -h, --help        Print help
