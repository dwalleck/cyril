Switch a macOS desktop app install to the standalone CLI

Usage: kiro-cli _ standalone-cutover [OPTIONS] <COMMAND>

Commands:
  check   Print whether this desktop app install should switch now, as one JSON line
  run     Install the standalone CLI at ~/.local/bin/kiro-cli, then start its finish
  finish  Remove the desktop app once the standalone is in place
  help    Print this message or the help of the given subcommand(s)

Options:
  -v, --verbose...  Increase logging verbosity
  -h, --help        Print help
